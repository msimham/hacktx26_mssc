# Create Training wizard: Sonnet prompt

Scaffold a new standalone Vite + React + TypeScript + Tailwind 4 + react-router app in `enterpriseplatform/app/`, and do all work inside `enterpriseplatform/` only: do not read, import from, or modify anything in `magicalsafety/`. Build a frontend-only "Create Training" wizard at `/create`, linked from a "+ Create Training" button on a simple `/` home page; there is no backend, so submitting just runs `console.log(state)`. The wizard has 5 steps, each using one reusable `PromptStep` component (a large free-text box with a helpful placeholder, plus suggestion chips that append their text to the box when clicked): (1) What do you want to train? [Team collaboration, Fire safety, Drug response, Onboarding]; (2) Who is it for? [New hires, Managers, Healthcare staff, Students, Sales teams]; (3) Which skills matter most? [Communication, Delegation, Decision making, Help-seeking, Conflict resolution, Adaptability]; (4) How many people will take part? [Solo, 2 people, 3–5 people, 6+ people]; (5) How should people interact? [Voice, Text, Image]. Store every answer as a string in one `useReducer` in `src/routes/CreateTraining.tsx`, keep step definitions in `src/routes/create/steps.ts`, and show "Step N of 5", a progress bar and Back/Continue (enabled once the text box isn't empty) on each step, ending on a review screen with an editable card per answer above a "Create Training" button. Never show AI or technical settings, and make it clean, polished SaaS-style and mobile-friendly.
