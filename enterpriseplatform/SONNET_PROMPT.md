# Create Training wizard: Sonnet prompt

Work only inside `enterpriseplatform/app/` (new Vite + React + TS + Tailwind 4 + react-router app); never read or touch `magicalsafety/`. Build a frontend-only "Create Training" wizard at `/create`, opened from a "+ Create Training" button on `/`. It is 5 data-driven steps defined in `src/routes/create/steps.ts` as a typed `Step[]` (`id`, `question`, `placeholder`, `chips`): train [Team collaboration, Fire safety, Drug response, Onboarding], audience [New hires, Managers, Healthcare staff, Students, Sales teams], skills [Communication, Delegation, Decision making, Help-seeking, Conflict resolution, Adaptability], headcount [Solo, 2 people, 3–5 people, 6+ people], interaction [Voice, Text, Image]. One reusable, presentational `PromptStep` (free-text textarea; clicking a chip appends its text) is driven by a single typed `useReducer` in `CreateTraining.tsx` holding `Record<StepId, string>` and the step index. Show "Step N of 5", a progress bar and Back/Continue (disabled while the trimmed text is empty), then a review screen with an editable card per answer and a "Create Training" button that calls one `submitTraining(answers)` stub (`console.log`) so a backend can replace it later. Keep it accessible (labels, focus, aria-valuenow on the progress bar), strictly typed, mobile-friendly and polished, with no AI or technical wording anywhere in the UI.
