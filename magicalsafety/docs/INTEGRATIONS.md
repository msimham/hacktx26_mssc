# Integrations: what is live, mocked, or unverified

Status words are used strictly:
- **Live**: a real request succeeded. Only recorded here after it happened, with date and model id.
- **Implemented, unverified**: the code exists and is tested against stub servers and stub `fetch`; it has **never been run against the real service**. No real API call has been made by the implementer.
- **Mock / fallback**: the labeled fallback is what runs.
- **Working, local**: needs no external service.

## Your steps (the app works without any of them)

1. **Meta Model API key** (Muse Spark, Image, Voice): create a key at the Meta developer console (dev.meta.ai), add billing or credits, put it in `magicalsafety/.env` as `META_MODEL_API_KEY`, restart `npm run dev`. It is in public preview and may be US-only.
   - Optional: `META_ALLOW_CONTRIBUTOR=false` stays false unless you accept that content sent may be used to train Meta models.
2. **World art**: `npm run gen:assets -- --dry-run` shows the 32 images (about $0.32). Then `npm run gen:assets` once.
3. **Voice on other devices**: browsers only allow the microphone on `localhost` or HTTPS. Use a tunnel for HTTPS if you test on a phone.
4. **SerpApi**: create an account and key, set `SERPAPI_API_KEY`.
5. **Facebook**: create a Meta app (Consumer / "Authenticate and request data from users with Facebook Login"), add the Facebook Login product, add `http://localhost:5173` and your demo domain to App Domains and Valid OAuth Redirect URIs, keep it in Development mode and add demo accounts as Testers. Set `VITE_FB_APP_ID` (public) and `FB_APP_SECRET` (server only). Optional: `FB_ENABLE_FRIENDS=true` for the dev-mode friends list.
6. **Organizer passcode**: set `ORGANIZER_PASSCODE`.

After a real request works, tell the implementer the date and model id so this file can say **Live**.

## Data sent to Meta when a key is set

- **Muse Spark**: event ids, timings, role names, short chat excerpts (max 200 characters), computed metrics, organization objectives. No real names, tokens or secrets.
- **Muse Image**: only fixed, authored prompts (room art, portraits) and a generic, name-free recap prompt.
- **Muse Voice**: the recording and up to 40 vocabulary terms. The recording is held in memory, forwarded once, and never written to disk. Transcripts are returned to the player and not stored by the voice route.
- Contributor mode (cheaper, but content may be used to train Meta models) is never used unless the organization **and** the server both opt in.

## Facebook limits (realistic scope)

- Login uses `public_profile` only; it works for app admins/testers in Development mode with no App Review.
- Invites use the Share Dialog (needs only the app id and an allowed domain). Game requests and `invitable_friends` are closed to new web apps.
- `user_friends` returns only friends who also use this app and needs App Review for Live mode, so it is Development-only and unverified.
- We never request messages, groups, location, or friend lists of non-users, and never store Facebook tokens or user ids.
